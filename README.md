# MarketLab - 주식 투자 게임

## 프로젝트 소개

C언어로 만드는 콘솔 기반 주식 투자 게임이다.

처음에 100만 원을 가지고 시작해서 30일 동안 주식을 사고팔며 130만 원을 모으는 것이 목표다. 엔비디아, 테슬라, 삼성전자 등 실제 기업들이 등장하고, 매일 뉴스에 따라 주가가 달라진다.

단순히 주식을 사고파는 것보다는 뉴스를 보고 어떤 종목에 투자할지 고민하는 게임으로 만들고 싶었다. 하루 거래 횟수를 제한하고 중간 미션도 추가했다.

## 개발 환경

- C언어
- Visual Studio 2026
- Windows 콘솔

## 개발 과정

### 10주차 (11/9 ~ 11/15)
- 처음에는 블랙잭 게임을 만들려고 계획함
- 프로젝트 제안서 제출
- 코드 일부분 작성
- 주제가 마음에 들지 않아 변경하기로 결정

### 11주차 (11/16 ~ 11/22)
- 주식 투자 게임으로 주제 변경
- 게임 진행 방식과 사용할 종목 선정
- 구조체로 주식 정보를 관리하도록 작성
- 매수, 매도 및 수익률 계산 구현
- 뉴스에 따라 주가가 변하도록 구현
- 연결 리스트를 이용한 거래 기록 추가
- 저장 및 불러오기 기능 추가
- 미션과 점수 기능 추가
- 콘솔 색상과 뉴스 화면 수정

## 코드 구성

- `main.c` : 메뉴 및 사용자 입력
- `market.c` : 주가 변동, 매매, 뉴스 등 게임 기능
- `market.h` : 구조체와 함수 선언

## 실행 방법

Visual Studio 2026에서 프로젝트를 열고 `Ctrl + F5`로 실행한다.

C11과 UTF-8 컴파일 설정을 사용했다.

## 앞으로 할 일

- 뉴스 내용이 반복되는 부분 수정
- 주가 차트를 좀 더 보기 쉽게 변경
- 미션 난이도 조절
- 게임을 직접 플레이하면서 오류 확인
- 전체 화면 구성 마무리
