# MarketLab - 주식 투자 시뮬레이터

## 1. 프로젝트 소개

C언어를 이용해 제작한 콘솔 기반 주식 투자 시뮬레이터이다.

엔비디아, 테슬라, 삼성전자 등 실제 기업 7개를 대상으로 가상의 주식 거래를 진행할 수 있다. 경제 뉴스와 랜덤 변동률에 따라 종목별 주가가 변하며, 플레이어는 주식을 매수하고 매도하면서 자산을 관리한다.

초기 자금 100만 원으로 시작하여 30일 동안 목표 자산 130만 원을 달성하는 것이 기본 목표이다. 단순히 주식을 사고파는 것 외에도 투자 미션과 점수 시스템을 추가하였다.

## 2. 개발 환경

- 개발 언어: C
- 개발 도구: Visual Studio 2026
- 실행 환경: Windows 콘솔

## 3. 주요 기능

### 주식 거래
- 미국 및 한국 기업 7개 종목
- 주식 매수 및 매도
- 보유 현금과 평균 매수가 계산
- 보유 종목의 평가손익과 총자산 확인
- 하루 거래 횟수 제한

### 경제 뉴스
- 실제 경제 이슈를 참고한 뉴스
- 뉴스 제목과 본문 출력
- 뉴스 종류에 따라 종목별 주가 변동
- 랜덤으로 뉴스가 발생하도록 설정
- 관련 종목의 등락률 표시

### 투자 게임
- 30일 동안 투자 진행
- 날짜별 주가 차트
- 투자 미션 및 점수 시스템
- 시장 전망 기능
- 최종 투자 결과 확인

### 데이터 관리
- 구조체 배열을 이용한 종목 정보 관리
- 연결 리스트를 이용한 매수·매도 기록 관리
- 파일 입출력을 이용한 게임 저장 및 불러오기

## 6. 코드 구성

**main.c**
- 프로그램 실행
- 메뉴 선택 및 사용자 입력
- 각 기능의 함수 호출

**market.c**
- 주식 가격 변동
- 경제 뉴스 처리
- 주식 매수 및 매도
- 투자 미션 관리
- 거래 내역 관리
- 게임 저장 및 불러오기

**market.h**
- 구조체 정의
- 상수 정의
- 함수 선언

## 7. 실행 방법

1. Visual Studio 2026에서 프로젝트를 연다.
2. `main.c`, `market.c`, `market.h` 파일을 확인한다.
3. C11 및 UTF-8 컴파일 설정을 적용한다.
4. `Ctrl + Shift + B`로 빌드한다.
5. `Ctrl + F5`로 프로그램을 실행한다.

## 8. 앞으로의 계획

중간보고 이후에는 게임 진행 과정에서 발생하는 오류를 수정하고, 뉴스와 주가 차트의 화면 구성을 개선할 예정이다.

또한 30일 동안 직접 게임을 진행하며 목표 자산과 투자 미션의 난이도가 적절한지 확인하고, 최종 발표 전까지 전체 기능을 점검할 계획이다.
